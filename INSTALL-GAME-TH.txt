NFC Attendance PWA V2 + เกมการเขียนภาพฉาย
============================================

ชุดนี้ยึดโครงสร้าง V2 เดิมจากไฟล์ Backup ที่แนบมา และเพิ่มเฉพาะเมนูนักเรียนกับเกมภาพฉาย
ไม่ต้อง Run SQL ใหม่ และไม่เปลี่ยนฐานข้อมูล Supabase

สิ่งที่เพิ่ม
- /student : หน้าหลักนักเรียน เลือก "สื่อการสอน" หรือ "เกมการเขียนภาพฉาย"
- /student/game : เกมเลือกภาพฉายด้านหน้า ด้านบน และด้านขวา จำนวน 10 ข้อ
- หลังเช็กชื่อ NFC จะมีปุ่มไปสื่อการสอนและปุ่มเล่นเกม
- หน้า "สื่อการสอน" มีแท็บ หน้าหลัก / สื่อการสอน / เกมภาพฉาย / ออกจากระบบ
- คะแนนสูงสุดเกมเก็บเฉพาะในเครื่องนักเรียน (localStorage) ไม่เพิ่มตาราง Supabase

วิธีนำไปใช้กับโปรเจกต์เดิม
1) สำรองโฟลเดอร์โปรเจกต์เดิมก่อน
2) แตก ZIP ชุดนี้
3) คัดลอกไฟล์ทั้งหมดไปทับในโฟลเดอร์โปรเจกต์เดิม
   หมายเหตุ: อย่าลบ .env.local เดิมของคุณ เพราะชุดนี้ตั้งใจไม่ใส่ Secret/Key ส่วนตัวมาให้
4) เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

   npm.cmd run build

5) ถ้า Build ผ่าน ให้รัน:

   git add .
   git commit -m "Restore V2 and add orthographic projection game"
   git pull --rebase origin main
   git push origin main

6) รอ Vercel Deployment ล่าสุดขึ้น Ready แล้วทดสอบ

การทดสอบนักเรียน
- ถ้าเข้า /student/login โดยตรง หลังล็อกอินจะไป /student
- ถ้าเข้าจาก NFC ระบบจะกลับไปเช็กชื่อก่อนตามเดิม แล้วจะมีปุ่ม "ดูสื่อการสอน" และ "เล่นเกมการเขียนภาพฉาย"

ไม่มีไฟล์ migration เพิ่ม และไม่ต้องแก้ Supabase SQL สำหรับเกมนี้
