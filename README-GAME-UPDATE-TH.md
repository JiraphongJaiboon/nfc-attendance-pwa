# V2 + เกมการเขียนภาพฉาย

เวอร์ชันนี้ยึดโครงสร้างเดิมของ NFC Attendance PWA V2 และเพิ่มเฉพาะส่วนของนักเรียน:

- `/student` เมนูนักเรียนหลังล็อกอิน: เลือก **สื่อการสอน** หรือ **เกมการเขียนภาพฉาย**
- `/student/game` เกมฝึกเลือกภาพฉายด้านหน้า ด้านบน และด้านขวาจากชิ้นงานลูกบาศก์ 3 มิติ
- คะแนนเกมเก็บเฉพาะคะแนนสูงสุดในอุปกรณ์ด้วย localStorage ไม่เพิ่มตาราง Supabase
- เมื่อเข้าจาก NFC ระบบยังกลับไปเช็กชื่อตามเดิม และหลังเช็กชื่อมีปุ่มเข้าสื่อหรือเกม

ไม่ต้องรัน SQL เพิ่มสำหรับเกมนี้
